# INSPACE-Model-Rocketry-and-7U-CanSat
Model Rocketry Competition – IN-SPACe

Project work: Model Rocket and 7U CanSat Design

As part of the IN-SPACe model rocketry competition, I worked on the design and engineering analysis of a model rocket and a 7U CanSat.

My Contributions
- Designed the model rocket and 7U CanSat using SolidWorks.
- Performed static structural and dynamic simulations using ANSYS.
- Worked on the engineering design and review process.
- Prepared and contributed to the Preliminary Design Review (PDR) and Critical Design Review (CDR) presentations.

### Project Documentation
- `PDR/` – Preliminary Design Review presentation.
- `CDR/` – Critical Design Review presentation.
- `CAD_Models/` – CAD model documentation.
- `ANSYS_Simulations/` – Simulation documentation and results.
